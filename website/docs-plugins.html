Как написать плагин

Плагин — один файл .js (или .css, если нужен только стиль). Приложение выполняет его как тело функции, в которую передан единственный аргумент fgs с готовыми возможностями: кнопки, работа с текстом, диалоги, доступ к открытым заметкам. Ни сборки, ни пакетов, ни перезапуска: включили переключатель — плагин заработал, выключили — убрал за собой.

Файлы лежат в папке Документы/FgSNotes/plugins, как темы лежат в themes. На телефоне такой папки нет, поэтому плагины хранятся внутри приложения.

Плагин видит все ваши заметки и может делать всё, что умеет страница приложения. Приложение не запускает чужой код без вашего согласия: файл, положенный в папку вручную, стартует выключенным, а кнопка установки показывает предупреждение.

Установка

  1. Откройте настройки → «Плагины» и нажмите «Установить плагин».
  2. Выберите файл. Приложение спросит подтверждение и скопирует файл в папку plugins; плагин сразу включится.
  3. Кнопка плагина появится на левой панели. Когда их больше, чем помещается по высоте окна, лишние уходят в меню «…».

Вручную: положите файл в Документы/FgSNotes/plugins и включите его переключателем в том же списке. «Открыть папку» в настройках покажет её в проводнике. Удалить плагин можно кнопкой «Удалить» в списке: файл исчезнет и из папки.

Первый плагин

Сохраните это как hello.js и установите. На левой панели появится кнопка; по нажатию в заметку вставится приветствие.

// ==FgsPlugin==
// @name        Привет
// @version     1.0
// @description Вставляет приветствие с сегодняшней датой
// ==/FgsPlugin==
fgs.addButton({
    title: 'Вставить приветствие',
    icon: 'sparkles',
    run: editor => editor.insert('Привет! Сегодня ' + new Date().toLocaleDateString('ru-RU') + '\n')
});

Заголовок файла

Комментарий между ==FgsPlugin== и ==/FgsPlugin== читается без запуска кода и попадает в список плагинов. Все поля необязательны; без заголовка плагин называется по имени файла.

ПолеЗачем
@nameНазвание в списке и в подсказках
@versionВерсия: показывается рядом с названием
@descriptionОдно-два предложения: что делает плагин
@authorАвтор

Справочник API

Всё, что создано через fgs (кнопки, стили, диалоги), приложение убирает само, когда плагин выключают. Исключение — то, что вы добавили в страницу напрямую: за этим следите через fgs.onUnload.

ВызовЧто делает
fgs.addButton({ title, icon, run })Кнопка на левой панели (на телефоне — в панели форматирования). Лишние кнопки уходят в меню «…». run получает fgs.editor.
fgs.addStyle(css)Добавляет CSS на страницу, пока плагин включён. Цвета берите из переменных темы: var(--accent-color), var(--card-bg).
fgs.onPreview(fn)fn(element) вызывается после каждой перерисовки предпросмотра: можно менять готовый HTML.
fgs.onChange(fn)fn(text) вызывается, когда меняется текст заметки.
fgs.editor.get()Весь текст текущей заметки.
fgs.editor.set(text)Заменяет текст заметки.
fgs.editor.insert(text)Вставляет текст на место курсора или выделения.
fgs.editor.selection()Выделенный текст.
fgs.editor.cursor(){ from, to } — границы выделения в символах.
fgs.editor.replace(from, to, text)Заменяет участок текста.
fgs.documents()Открытые заметки: [{ id, title, content, active }].
fgs.openDocument(id)Переключается на заметку.
fgs.createDocument(title, text)Создаёт новую заметку и открывает её.
fgs.markdown(text)Превращает Markdown в HTML тем же разборщиком, что и предпросмотр.
fgs.download(name, data, type)Предлагает скачать файл. data — строка или Blob.
await fgs.pickFile({ accept, as })Окно выбора файла. Результат: { name, type, size, data } или null. as: 'text', 'dataUrl' или 'arrayBuffer'.
fgs.modal({ title, width })Диалог поверх приложения. Возвращает { body, close }. Закрывается по Esc и по щелчку снаружи.
fgs.openTab({ title, icon, render })Отдельная вкладка рядом с заметками, содержимое которой рисует плагин: render(element, tab) вызывается один раз, повторный вызов с тем же key просто показывает вкладку. tab: close(), backToNote(), setTitle(text).
fgs.storage.get(key, fallback) / set(key, value)Личное хранилище плагина: значения сохраняются между запусками.
fgs.notify(text)Короткое сообщение в строке состояния (3 секунды).
fgs.onUnload(fn)fn вызовется при выключении плагина: уберите всё, что создали сами (таймеры, слушатели на document).
fgs.version, fgs.fileВерсия API (сейчас 1) и имя файла плагина.

Своя SVG-разметка

Строка, начинающаяся с <, вставляется в кнопку как есть. Рисуйте на сетке 16×16 и берите цвет из currentColor, тогда значок подхватит тему и акцент. Размер задаёт приложение (20 пикселей на левой панели, 16 в меню). Если имя неизвестно, показывается sparkles.

fgs.addButton({
    title: 'Звезда',
    icon: '<svg viewBox="0 0 16 16" fill="none" stroke="currentColor" stroke-width="1.2" stroke-linecap="round" stroke-linejoin="round"><path d="M8 2l1.8 3.7 4 .6-2.9 2.8.7 4L8 11.2 4.4 13.1l.7-4L2.2 6.3l4-.6z"/></svg>',
    run: editor => editor.insert('★')
});

Диалоги

fgs.modal отдаёт пустое тело, которое вы наполняете сами. Для единого вида в нём работают готовые классы: pm-btn и pm-btn primary (кнопки), pm-row (строка с отступами), pm-muted (приглушённый текст); поля ввода и списки оформлены автоматически.

fgs.addButton({
    title: 'Счётчик слов',
    icon: 'info',
    run() {
        const { body } = fgs.modal({ title: 'Счётчик слов', width: 360 });
        const words = fgs.editor.get().trim().split(/\s+/).filter(Boolean).length;
        body.innerHTML = '<p>Слов в заметке: <strong id="n"></strong></p>';
        body.querySelector('#n').textContent = words;   // текст — через textContent, не через innerHTML
    }
});

Вкладка или окно

Короткое действие (выбрать, подтвердить, показать результат) удобнее в диалоге fgs.modal. Всё, что требует места и живёт долго — календарь, доска для рисования, большой список, — лучше открыть вкладкой: она стоит в одном ряду с заметками, не закрывает их и сохраняется при переключении.

fgs.addButton({
    title: 'Мой экран',
    icon: 'columns',
    run() {
        fgs.openTab({
            key: 'main', title: 'Мой экран', icon: 'columns',
            render(element, tab) {
                element.innerHTML = '<div style="padding:24px"><button id="go">В заметку</button></div>';
                element.querySelector('#go').addEventListener('click', () => { tab.backToNote(); fgs.editor.insert('Привет!'); });
            }
        });
    }
});

Вкладка не содержит текста: сочетания сохранения на ней не работают, а текстовый редактор остаётся привязан к последней открытой заметке. Чтобы вставить текст, сначала вызовите tab.backToNote(). Событие plugin-view-show на element приходит каждый раз, когда вкладку снова показывают: обновите в нём данные.

Рецепты

Изменить предпросмотр

fgs.addStyle('.reading-time { color: var(--text-muted); font-size: .9em; }');
fgs.onPreview(preview => {
    const words = preview.innerText.trim().split(/\s+/).length;
    const note = document.createElement('p');
    note.className = 'reading-time';
    note.textContent = 'Чтение: ' + Math.max(1, Math.round(words / 180)) + ' мин';
    preview.prepend(note);
});

Сочетание клавиш

Свои сочетания вешаются обычным слушателем; уберите его при выключении плагина.

const onKey = event => {
    if ((event.ctrlKey || event.metaKey) && event.shiftKey && event.code === 'KeyD') {
        event.preventDefault();
        fgs.editor.insert(new Date().toISOString().slice(0, 10));
    }
};
document.addEventListener('keydown', onKey);
fgs.onUnload(() => document.removeEventListener('keydown', onKey));

Запомнить настройку

const count = fgs.storage.get('opened', 0) + 1;
fgs.storage.set('opened', count);
fgs.notify('Плагин запущен ' + count + '-й раз');

Сохранить файл

fgs.addButton({
    title: 'Сохранить как .txt',
    icon: 'download',
    run: editor => fgs.download('заметка.txt', editor.get())
});

Готовые большие примеры (экспорт в Word, календарь, презентации, рисование, распознавание текста) — в магазине: у каждого плагина есть кнопка «Код».

Ограничения

  • Запросы в интернет. Плагин работает на странице приложения, поэтому браузерные правила CORS действуют и на него: fetch получит ответ, только если сервер разрешает чужие запросы. Подходят открытые API с заголовком Access-Control-Allow-Origin (например, OpenAlex); arXiv и многие сайты такого заголовка не отдают.
  • Нет доступа к файловой системе. Читать и писать файлы можно только через fgs.pickFile и fgs.download. Node.js и API Electron плагину недоступны.
  • Безопасность. Тексты из заметок и чужих данных вставляйте через textContent. Если используете innerHTML, экранируйте значения: заметка может содержать произвольную разметку.
  • Скорость. onPreview и onChange вызываются при каждом нажатии клавиши: не делайте в них тяжёлых вычислений, а лучше отложите работу таймером.
  • Ошибки. Исключение при запуске не ломает приложение: плагин остаётся в списке, а текст ошибки появляется красным под его названием в настройках. Ошибки обработчиков пишутся в консоль.
  • Телефон. Кнопки уходят в панель форматирования, а окна должны помещаться в узкий экран: задавайте width как максимум, а не как точный размер.

Публикация

Хотите, чтобы плагин появился в магазине? Откройте запрос на слияние в репозитории:

  1. Положите файл в папку plugins-examples с заполненным заголовком.
  2. Добавьте запись о нём в plugins-examples/catalog.json: категория, значок (содержимое SVG на сетке 16×16), аналог в Obsidian, если есть, и пометка «нужен интернет».
  3. Выполните node scripts/build-plugins-site.js: скрипт скопирует файл на сайт и обновит каталог.
Перед отправкой проверьте плагин на пустой и на большой заметке, включите и выключите его несколько раз подряд и убедитесь, что кнопки и слушатели исчезают.
